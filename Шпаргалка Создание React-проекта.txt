🛠 Шпаргалка: Создание React-проекта «по-взрослому» (FSD + Vite + RTK)
1. Инициализация и Окружение
Создание: npm create vite@latest my-app -- --template react-ts

Порт (по ТЗ): В vite.config.ts строго прописать server: { port: 3000 }.

Git: git init -> создаем .gitignore -> первый коммит в main.

2. Настройка Алиасов (Paths)
Чтобы работал импорт через @/:

Vite: В vite.config.ts добавить resolve: { alias: { '@': path.resolve(__dirname, './src') } }.

TypeScript: В tsconfig.app.json добавить "baseUrl": "." и "paths": { "@/*": ["./src/*"] }.

VS Code: Перезапустить TS Server (Ctrl+Shift+P), чтобы ошибки исчезли.

3. Архитектура FSD (Feature Sliced Design)
Разделяем код на слои внутри src/:

app/ — провайдеры (Redux, Router), глобальные стили.

pages/ — целые экраны приложения.

widgets/ — крупные блоки (Хедер, Список вопросов).

features/ — действия пользователя (Поиск, Фильтрация).

entities/ — бизнес-логика (Вопрос, Скилл, Юзер).

shared/ — UI Kit (Кнопки, Инпуты) и конфиг API.

4. Настройка State Management (Redux + API)
Shared слой: Создаем baseApi.ts через createApi из @reduxjs/toolkit/query/react.

Entities слой: Используем baseApi.injectEndpoints для создания конкретных запросов (например, getQuestions). Это позволяет держать API модульным.

Store: Подключаем api.reducer и api.middleware в configureStore.

5. Роутинг и URL Sync
Устанавливаем react-router-dom.

Важное правило: Состояние фильтров и пагинации храним в URL через useSearchParams. Это делает ссылки "живыми".
